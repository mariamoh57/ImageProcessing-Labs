# Image Processing Labs (ARTI407)

## Overview
This repository contains a collection of laboratory assignments for the **ARTI407 - Image Processing** course. The labs focus on bridging the gap between theoretical computer vision concepts and practical implementation using Python.

## Technologies & Libraries Used
* **Programming Language:** Python 3
* **Core Libraries:** 
  * `NumPy`: For core matrix operations and multidimensional array manipulations.
  * `OpenCV (cv2)`: For reading, processing, and exporting image data.
  * `scikit-image`: For advanced image processing algorithms and built-in datasets.
  * `PIL`: For alternative image rendering and resampling techniques.
  * `Matplotlib`: For data and image visualization.

## Repository Structure

### [Lab 1: Python Programming Basics](./Lab1)
* Foundational array manipulation using NumPy.
* Matrix indexing, slicing, and sub-array extraction.
* Loading, displaying, and saving images using OpenCV and PIL.

### [Lab 2: Digital Image Fundamentals](./Lab2)
* **Sampling & Quantization:** Understanding spatial and intensity resolution downsampling.
* **Arithmetic Operations:** Image addition, subtraction, and brightness adjustments.
* **Logical/Set Operations:** Applying Bitwise AND, OR, XOR, and NOT for image masking and region extraction.
